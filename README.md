# Local Views for YouTube

Расширение для Chrome, которое показывает под видео на YouTube, сколько раз вы сами его смотрели. Все данные хранятся локально в `chrome.storage.local` и никуда не отправляются.

## Что считается просмотром

- Видео реально проигралось 5 секунд. Перемотка время не добавляет, пауза и реклама тоже. Видео короче 5 секунд засчитывается, когда проиграно 90% его длины.
- Повтор после окончания и каждый круг в режиме loop — новый просмотр.
- Просмотры в фоновых вкладках и в мини-плеере засчитываются.
- Shorts, встроенные плееры на других сайтах и YouTube Music пока не учитываются.

## Разработка

Нужен Node.js 24 LTS.

```bash
npm install
npm run build      # собирает расширение в dist/
npm test           # юнит-тесты (vitest)
npm run typecheck
npm run icons      # перерисовывает public/icons/*.png
```

Как загрузить в Chrome: откройте `chrome://extensions`, включите «Режим разработчика», нажмите «Загрузить распакованное расширение» и выберите папку `dist/`. После каждой пересборки нажимайте ⟳ на карточке расширения и обновляйте вкладку YouTube.

## Устройство

- `src/bridge/` — скрипт в main world страницы. Слушает события `<video>` основного плеера (`#movie_player`), берёт ID видео из `getVideoData()` и пересылает состояние в content script.
- `src/content/` — content script в isolated world: считает просмотры, сохраняет их и рисует бейдж под видео. Все селекторы DOM YouTube собраны в `badge.ts`.
- `src/core/` — чистая логика без браузерных API: правила подсчёта (`view-tracker.ts`), формат записей (`storage.ts`), множественные числа (`format.ts`).
- `public/` — манифест, локализации (`_locales/en`, `_locales/ru`) и иконки.
